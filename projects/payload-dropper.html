Case study / EMBEDDED CONTROL

Position-feedback
payload release.

Replaced a servo-based approach with a feedback-controlled linear actuator and made the firmware responsive while the mechanism moves.

ROLE: FIRMWARE · PCB · TESTDATE: JAN — SEP 2026PLATFORM: PIC

At a glance

The dropper releases a payload on command. The module moved from a servo to a linear actuator with position feedback, driven by an H-bridge and a PIC microcontroller.

Embedded C / XC8PICH-bridgeUARTKiCad

The problem

Software PWM blocked serial communication. The actuator also needed position feedback so the firmware could manage movement and detect a stall.

The approach

I implemented non-blocking actuator control with position feedback, a deadband, and a stall timeout.

To keep serial communication responsive during actuator control, I moved UART handling to an interrupt-driven routine and tuned the clock for baud-rate accuracy. I implemented framed serial messages with an integrity check, heartbeat, and acknowledgements.

Board & manufacturing

I designed the module PCB and changed the design rules so it could use a lower technology class. This reduced PCB cost by about 30% and halved lead time.

Outcome & learning

I built a test rig for batch testing and prepared production documentation. The project reinforced that the control loop and communication path need to work together under real-time constraints.
