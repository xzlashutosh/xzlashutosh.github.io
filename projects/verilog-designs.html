At a glance

The repository groups small digital design exercises, from basic sequential elements through arithmetic structures. It includes implementations for adders, flip-flops, ripple counters, and multipliers.

16-bit Harvard architecture processor

An earlier course project described on my previous portfolio explored a 16-bit Harvard architecture in Verilog. The design included 32 16-bit registers, logic and unsigned fixed-point arithmetic, a load/store unit, 256 × 16-bit data memory, 64 × 32-bit instruction memory, a 6-bit program counter, and a 32-bit instruction set.
