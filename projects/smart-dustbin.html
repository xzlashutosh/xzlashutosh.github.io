Prototype / COMPUTER VISION

Smart Dustbin
classifier.

A Raspberry Pi camera prototype that runs an image classifier and displays the predicted material label, confidence, and inference time.

ROLE: CAMERA · ML INFERENCELANGUAGE: PYTHONRUNTIME: TENSORFLOW LITE

At a glance

The project captures a continuous camera stream and classifies each frame with a TensorFlow Lite model. The repository's label set contains cardboard, glass, metal, organic, paper, plastic, and trash.

Raspberry Pi CameraTensorFlow LitePythonImage classification

Inference pipeline

The Python program initializes the TFLite interpreter and loads the model labels. It resizes each camera frame to the model input dimensions, runs inference, and displays the top predicted class with its confidence and processing time.

The camera loop is configured for a 640 × 480 preview at 30 frames per second. The repository demonstrates classification and on-screen annotation; it does not document an actuator or an automated sorting mechanism.
