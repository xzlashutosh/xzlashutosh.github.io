Case study / EMBEDDED HARDWARE

Klein physiological
monitor.

A prototype physiological monitoring system combining a custom PCB, sensors, microcontroller firmware, and an on-demand display of vital measurements.

ROLE: PCB · EMBEDDED FIRMWAREDATE: JAN — MAY 2021TYPE: UNDERGRADUATE PROJECT

At a glance

Klein is a functional prototype that monitors and displays body temperature, heart rate, blood oxygen, and ECG on demand. It also displays the current date, day, month, and local time.

PCB designMicrocontrollerADCInterruptsEmbedded C

System design

I developed the device electronics and firmware for acquiring and displaying physiological measurements. The repository includes Eagle schematic and layout files with two temperature sensor variants: MLX90614 and TMP117.
