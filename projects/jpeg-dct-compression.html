A MATLAB implementation that explores the JPEG image compression and decompression process with sample outputs at different quality settings.

ROLE: IMPLEMENTATIONLANGUAGE: MATLABMETHOD: DCT-BASED JPEG

At a glance

The project provides MATLAB scripts for image loading, transformation, compression, and decompression. It includes the source image alongside sample compressed outputs for quality settings Q10 and Q50.

Code and outputs

The repository separates the main workflow from image transformation and compression or decompression functions. It also includes a transformed image and compressed examples so the output can be compared against the source.
