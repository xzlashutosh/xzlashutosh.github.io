At a glance

At Tundra Drone Technologies, I work across the electronics and firmware in a modular payload system. My contributions include leading the electronics work on a two axis gimbal and its Laser extension, designing module boards, improving real time communication, and preparing designs for production.

Selected work: six board designs or redesigns across the gimbal, Laser, Dropper, FPV Light, BASE v2 connector, and Strobe, alongside firmware for gimbal control, Laser, Dropper, and BASE.

The system

The platform uses a BASE unit fitted to the drone, with mission modules attached through a shared interface. My work has covered the drone communication path, BASE to module communication, and electronics and firmware within several of those modules.

Gimbal and Laser

I led the electronics work for an in house two axis stabilized gimbal and its Laser extension. I designed the gimbal controller PCB and the Laser control and IMU board, wrote firmware for quaternion based gimbal control, and integrated drone attitude data.

The Laser firmware handles PWM, a framed serial protocol with heartbeat, calibration from the user interface, and temperature warnings and protection. I brought up and calibrated magnetic encoders, tuned stabilization, and analyzed vibration using logged gyro data. I also traced power supply shutdowns to current headroom and transient demand, and investigated magnetic interference with the drone heading reference.

Inductive position sensing

To address magnetic interference and pursue improved pointing accuracy, I selected an inductive sensing approach for the gimbal axes. I designed transmitter and receiver coils, simulated air gap and target material against the accuracy target, selected a configuration within the mechanical limits, and designed a sensor PCB for integration with the controller.

Read the inductive sensor case study ↗

Dropper module

I designed the module PCB around an H bridge actuator drive and wrote firmware for a linear actuator with position feedback. The controller uses non blocking movement logic with a deadband and stall timeout. I moved serial handling to an interrupt driven routine to resolve timing conflicts with software PWM, and implemented framed communication with integrity checks, heartbeat, and acknowledgements.

PCB design rule changes reduced fabrication cost by about 30% and halved lead time. I also built a test rig and prepared documentation for production.

Read the Dropper case study ↗ · See Tundra’s DROP module ↗

FPV Light

I completed the PCB design for a visible and infrared lighting module, including the LED driver architecture, schematic, layout, bill of materials, and production data. The design includes PWM dimming and protection circuitry. I worked through the manufacturing constraints of the aluminum substrate boards and prepared a bill of materials with component origin checked for each part.

Read the FPV Light case study ↗ · Browse Tundra’s lighting modules ↗

BASE interface and firmware

I updated the BASE firmware to keep drone commands reliable while sensor data streamed, using a non blocking buffered main loop and deployment through the drone SDK. On the module side, I moved serial handling to interrupt driven buffers so PWM work would not block the communication heartbeat. I also added automatic left or right port detection and heartbeat forwarding.

For BASE v2, I designed a spring loaded connector board and selected critical parts. I contributed to the shared drone agnostic module protocol, wrote a bench test procedure, and supported batch assembly.

Strobe redesign

I redesigned the compact anti collision strobe PCB across several revisions. I relocated tall components, combined two connectors, cleared design rule errors, set current limiting, selected the high power LED, and prepared a panelized fabrication release.

Read the Strobe case study ↗ · See Tundra’s Strobe module ↗

Production and debug support

I prepared production release packages for several boards, including bills of materials, drawings, Gerbers, pick and place files, programming notes, and test instructions. I supported fabrication feedback, assembly start up, jigs, rework guidance, sourcing, and test procedures.

On existing designs, I helped trace a low current fault on the SPOTLIGHT driver board with the senior electronics engineer, cleared design rule violations on a battery management board before fabrication, and supported oscilloscope based signal and power rail diagnostics.
